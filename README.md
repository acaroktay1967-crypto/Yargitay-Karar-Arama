# Hukuk Pro — Web Sürümü ⚖️

Kapsamlı Türk Hukuku yazılımının tarayıcı uyumlu web versiyonu.

## 🚀 Özellikler

- **📝 Dilekçe Yazma**: 44+ profesyonel şablon kütüphanesi
- **⚖️ Hâkim Karar Yazım**: 28 dava türü, otomatik harç/vekâlet hesaplama
- **📋 Karar Örnekleri**: Hüküm, Taşınmaz, Nüfus, İcra karar örnekleri
- **🧮 Hesaplama Araçları**: 2024 tarife ile harç, vekâlet, faiz hesaplama
- **📤 Üst Yargı Yolu Rehberi**: İstinaf, Temyiz, AYM, AİHM bilgileri ve süre hesaplayıcı
- **💾 Kayıtlı Belgeler**: Belgelerinizi tarayıcı deposunda saklayın

## 🌐 Kullanım

1. `index.html` dosyasını bir web tarayıcısında açın
2. Veya herhangi bir web sunucusu ile çalıştırın:

```bash
# Python ile
python3 -m http.server 8080

# Node.js ile  
npx serve .
```

3. Tarayıcınızda `http://localhost:8080` adresine gidin
